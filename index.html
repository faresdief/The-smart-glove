      HOW IT WORKS

      1Sense. Every finger is a virtual flex sensor: bent = 1, extended = 0.
      2Encode. The five sensors form a 5-bit word (T-I-M-R-P), e.g. 01100.
      3Match. A hash-map lookup resolves the word in O(1). Unknown codes fall back to a Hamming-distance suggestion.
      4Output. The word is typed on the 16×2 LCD and spoken by the browser's built-in SpeechSynthesis engine. No server, no network calls beyond the CDN libraries.

      The same dictionary and encoding map directly onto a physical glove (flex sensors → microcontroller ADC → thresholds → 5-bit code), making this simulator a software twin for testing vocabularies before any hardware exists.
